# Agent guide

Code and measurement records for "The parity gap in crystal tensor prediction". Humans: start with
[README.md](README.md). This file is the short operational version for coding agents.

## Environment

- Python 3.12, managed with `uv`; never `pip install`. Run everything as `uv run ...`.
- Extras: `verify` (release checks), `nequip` or `mace` (training; **mutually exclusive**, since
  they pin different e3nn versions), `data` (dataset preparation), `analysis` (aggregation).
- No GPU is needed for anything except `equiparity run`.

## Entry point

Everything goes through the `equiparity` CLI. Use `--json` when parsing output; non-zero exit
means failure.

```bash
uv run equiparity --help
uv run equiparity verify --json                 # theory + claims; must pass before any change lands
uv run equiparity records list --json           # what each results/ file holds and backs
uv run equiparity records show stats --json
uv run equiparity grid generate main            # configs/grid/*.yaml
uv run --extra nequip equiparity run configs/grid/nequip_piezoelectric_o3_seed0.yaml
uv run equiparity manifest                      # rebuild results/run_manifest.json
```

## Checks

```bash
uv run ruff check . && uv run ruff format --check .
uv run mypy src/equiparity/domain src/equiparity/io src/equiparity/data \
  src/equiparity/reproducibility.py src/equiparity/cli.py src/equiparity/workflows/grids.py \
  src/equiparity/workflows/run_manifest.py src/equiparity/verification/parity_gap.py \
  src/equiparity/verification/release.py
uv sync --extra nequip --extra verify && uv run pytest -q   # or --extra mace
```

## Rules

- `results/` holds frozen records. Do not edit them by hand. Every file there must be listed in
  `results/index.json` (a test enforces it); add new records through the command that produces
  them and index them in the same change.
- `results/run_manifest.json` is generated. After changing anything under `configs/`, run
  `equiparity manifest`; a test fails if it is stale.
- `configs/` is generated by `equiparity grid generate`; a test checks the generator reproduces
  the committed configs byte-for-byte. Change the generator, not the YAML.
- Library code lives in `src/equiparity/`; the CLI in `cli.py` only parses arguments and dispatches.
- Tests mirror the package layout under `tests/`.
